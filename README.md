# ПРОФИ РЕМОНТ — демонстрационный сайт ремонтной бригады

Статический сайт на HTML/CSS/JS без зависимостей. Сделан как демо-проект для портфолио: можно показывать мастерам, прорабам и ремонтным компаниям как пример того, какой сайт вы можете для них сделать.

## Структура проекта

```
profi-remont/
├── index.html   — разметка и весь контент страницы
├── style.css    — все стили (дизайн-токены, секции, адаптив)
├── script.js    — вся интерактивность (меню, калькулятор, галерея, FAQ, форма)
└── README.md    — этот файл
```

Внешние изображения подключены напрямую по ссылкам на Unsplash и Pexels (бесплатные лицензии, разрешено коммерческое использование). Шрифты — через Google Fonts.

## 1. Как запустить сайт локально

Файлы не требуют сборки — достаточно браузера.

- **Проще всего**: откройте `index.html` двойным кликом — сайт откроется в браузере.
- **Через локальный сервер** (рекомендуется, чтобы избежать особенностей открытия файлов напрямую через `file://`):
  - Если установлен Python: `python3 -m http.server 8000` в папке проекта, затем откройте `http://localhost:8000`.
  - Если установлен VS Code: расширение "Live Server".

## 2. Как проверить на телефоне

- Запустите локальный сервер (см. выше) на компьютере.
- Убедитесь, что телефон подключён к той же Wi-Fi сети, что и компьютер.
- Узнайте локальный IP компьютера (например, `192.168.1.25`) и откройте на телефоне `http://192.168.1.25:8000`.
- Проверьте: мобильное меню (бургер), калькулятор, галерею с увеличением фото, аккордеон FAQ и отправку формы.
- Также проверьте сайт в Safari на iPhone — отдельно от Chrome/Android, так как в брифе это было отдельным требованием.

## 3. Как бесплатно разместить на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `profi-remont`).
2. Загрузите туда файлы `index.html`, `style.css`, `script.js` (через веб-интерфейс GitHub — "Add file → Upload files", либо через `git push`).
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Source** выберите ветку `main` и папку `/root`, сохраните.
5. Через 1–2 минуты сайт будет доступен по адресу вида `https://ваш-логин.github.io/profi-remont/`.

## 4. Что обязательно заменить перед передачей сайта реальному клиенту

Сайт специально собран как демонстрационный — часть данных нужно заменить на настоящие:

- **Контакты** (секция «Контакты» и подвал): телефон, Telegram, WhatsApp, график работы — сейчас это плейсхолдеры с пометкой «замените».
- **Отзывы**: карточки в разделе «Отзывы» помечены как примеры оформления — замените реальными отзывами клиентов.
- **Портфолио**: фотографии в разделе «Работы» — демонстрационные стоковые фото. Замените на фотографии реальных выполненных объектов.
- **Форма заявки**: сейчас отправка работает только в демо-режиме (показывает подтверждение, но ничего никуда не отправляет). Чтобы заявки реально приходили, нужно подключить один из вариантов:
  - Telegram-бот (Bot API) — заявка приходит сообщением в чат;
  - сервис отправки писем (например, Formspree, EmailJS или собственный backend);
  - свой сервер/CRM.
- **Калькулятор**: коэффициенты стоимости — условные, только для демонстрации механики расчёта. Перед реальным использованием их нужно заменить на актуальные цены компании (или оставить как ориентир с чёткой пометкой, как сейчас).
- **Юридические документы**: ссылки «Политика конфиденциальности» и «Договор оферты» в подвале — заглушки, страниц нет. Добавьте реальные документы перед запуском.
- **Favicon/лого**: сейчас это простая SVG-заглушка с инициалами «ПР» — замените на реальный логотип компании.
